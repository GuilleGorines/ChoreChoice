# ChoreChoice

## Introducción
Este repositorio contiene el proyecto de la App ChoreChoice, que se basa en un sistema que aleatoriza reparto y elección de tareas. 
ChoreChoice soluciona la necesidad de tener que elegir la próxima tarea a realizar, dado que se elige de manera aleatoria.

## Plan inicial
ChoreChoice es una app desarrollada en _Kotlin_ (motivo: me apetece).
Se trata de una app **local*. Con lo cual, no se espera (en un comienzo) tener que conectar a fuentes externas.
Por lo tanto, se preveen el diseño y desarrollo de los siguientes sistemas:
  - sistema de pantallas y escenas
  - sistema de guardado de tareas en dispositivo
  - sistema de notificaciones
